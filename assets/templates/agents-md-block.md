## Looprch

This project is executed with Looprch from its SEV3 specification (`phases/manifest.json`).

- Run `/lr-status` (or `looprch status` in a terminal) to see the current phase and next step.
- Never tick boxes in `phases/todo.md`; only Looprch does that after verified evidence.
- Never commit as an agent; Looprch makes every commit.
- Never edit files under `.looprch/` by hand; the `looprch` CLI owns them.
- If Looprch gave you a brief, follow it exactly and end with the result block it asks for.
